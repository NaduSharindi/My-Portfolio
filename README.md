# Nadunika Sharindi — Portfolio

Personal portfolio site built with HTML, CSS, and vanilla JavaScript (no frameworks).

## Run locally

### Option 1 — Open the file
Double-click `index.html`, or open it in your browser.

### Option 2 — Local server (recommended)
From this folder in a terminal:

```bash
# Python 3
python -m http.server 5500
```

Then visit [http://localhost:5500](http://localhost:5500).

Or with VS Code / Cursor: install the **Live Server** extension and use “Open with Live Server”.

## Edit later

| File | What to change |
|------|----------------|
| `index.html` | Copy, projects, contact links, sections |
| `style.css` | Colors in `:root` / `[data-theme="dark"]` |
| `script.js` | Theme, nav, scroll animations |
| `assets/profile.png` | Replace with a higher-resolution photo |
| `assets/favicon.svg` | Favicon initials / color |

Update LinkedIn and GitHub URLs in the Contact section of `index.html` if your profile paths differ.
